Build a voice agent in the browser

    What you'll build

    A voice agent you can talk to, running entirely in Chrome. There's no server and no API key: the language model, speech-to-text, text-to-speech and voice detection all run on your laptop.

    You build it in six layers. Each step adds a few lines to the agent's code, right here on this page. You press Run and talk to the result.

    StepWhat it addsModel

    You need

    • Desktop Chrome 148 or later, on a laptop with at least 22 GB of free disk space
    • A microphone, and headphones help

    Set up Chrome

    Gemini Nano is a language model built into Chrome. From Chrome 148 any web page can use it, so you don't need to change any settings or flags.

    1. Open chrome://settings/help. If Chrome offers an update, install it and relaunch. The version must be 148 or higher.
    2. Come back to this page and look at Gemini Nano in the box below.
    If Gemini Nano saysDo this
    Not downloaded yetAll good. You download it in the next step.
    ReadyAll good, it's already on this laptop.
    Not in this browserYour Chrome is older than 148, or isn't desktop Chrome. Update it and relaunch.
    This device can't run itThe laptop doesn't have enough disk space, memory or graphics power. Pair up with someone whose laptop works.
    The speech models use WebGPU, which runs them on the graphics chip. It's on by default in Chrome. Without it they still work, just slower.

    Download the models

    Press Download models and keep this tab open until every row says Ready. Gemini Nano is about 4 GB, so it can take a few minutes. The others are small.

    The models stay on your laptop afterwards, so next time they load in a few seconds.

    Step 1: Ask Gemini Nano

    LanguageModel.create() opens a session on Gemini Nano. The system prompt asks for short, spoken-style replies, because later the agent reads them aloud.

    onText() runs when you press Send. The two lines that ask the model and show the answer are turned off.

    1. Select the two lines marked STEP 1 and press ⌘ / (Mac) or Ctrl / (Windows) to turn them on.
    2. Press Run, then type a question and press Send.

    Step 2: Hear the answer

    tts is Kokoro, a small text-to-speech model. tts.speak() turns text into speech and plays it.

    1. Turn on the STEP 2 line.
    2. Press Run and send a message. The agent reads its answer aloud.

    Step 3: Speak instead of typing

    While you hold Hold to talk, the page records the microphone. When you let go, it passes the audio to onVoice().

    transcribe() uses Whisper, a speech-to-text model, to turn the audio into text. The text then goes through onText(), the same path as typing.

    1. Turn on the two STEP 3 lines.
    2. Press Run. Hold Hold to talk, ask a question, and let go. Chrome asks to use the microphone the first time.

    Step 4: Real time

    Until now the agent waits for Gemini Nano to write the whole answer, then speaks. That's a long silence.

    promptStreaming() hands over the answer a few words at a time. As soon as a whole sentence has arrived, it goes to Kokoro. So the agent starts talking while the model is still writing the rest.

    1. Turn on the STEP 4 line in onText(). It replaces the three lines above it, which are now off.
    2. Press Run and ask for something long, like a short story. Notice how quickly it starts speaking.

    Step 5: Hands-free with voice activity detection

    No more button. vad is Silero VAD, a voice activity detection model. It listens to the microphone, checks every 32 ms whether someone is speaking, and calls you back when you start and when you stop.

    startCall() runs when you press Start call. When you stop talking, your audio goes to onVoice(), the same as letting go of the button.

    The agent would hear itself through your speakers and answer itself. The two vad.pause() and vad.resume() lines stop it listening while it talks.

    1. Turn on all the STEP 5 lines. Select them together and press ⌘ / once.
    2. Press Run, then Start call, and just talk.

    Step 6: Turn detection

    The VAD treats any short pause as the end of what you're saying. Pause to think in the middle of a sentence and the agent jumps in.

    turn is Smart Turn, a model that listens to how your voice ends: falling tone, a finished phrase, or a trailing "um". At each short pause the VAD asks it "has the user finished?" and only ends your turn when the answer is yes. The chat shows how sure it was.

    1. Turn on the STEP 6 lines.
    2. Press Run, then Start call. Say "I'd like to know… um…" and pause, then finish the question.

    What you built

    A voice agent with real-time replies, hands-free listening and turn detection, in about 70 lines of code. Every model ran on your laptop: nothing you said left it.

    Things to try

    • Change SYSTEM_PROMPT to give the agent a different job, like a pirate or a quiz host, and press Run.
    • Try a different Kokoro voice, or speak in another language.

    The full project, with a production version of this agent, is in the browser-native-conversational-agents repo.
